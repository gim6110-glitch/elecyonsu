# ✅ v8 새로고침 로그인 유지·관리 화면 복원 (2026-11-04)

- 새로고침 시 Supabase `getSession()`의 `data.session.user`를 정확하게 읽도록 수정했습니다. 기존에는 `data.user`를 조회해 항상 로그인 화면으로 이동하는 문제가 있었습니다.
- Supabase Auth의 세션 저장·자동 갱신을 명시적으로 활성화합니다. 안전한 인증 없이 화면만 유지하는 우회 로그인은 사용하지 않습니다.
- 동일 탭에서 새로고침하면 현재 열어둔 **연수 상세 관리 화면과 스크롤 위치**를 복원합니다. 활성 연수 ID만 `sessionStorage`에 저장하며 이메일·비밀번호·서명 데이터는 저장하지 않습니다.
- 관리자 로그아웃 버튼을 화면 상단 오른쪽에 배치하고, 기존 연수 목록의 중복 버튼을 제거했습니다. 연수 참석자 QR 서명 화면에서는 로그아웃 버튼이 보이지 않습니다.
- 직접 로그아웃하거나 세션이 만료되었을 때에는 다시 로그인해야 합니다. 시크릿 모드 또는 브라우저 저장소 차단 환경에서는 로그인 유지가 제한될 수 있습니다.
- Supabase SQL 수정은 필요하지 않습니다. GitHub 배포 후 로그인 → 연수 상세 화면 → 새로고침 → 로그아웃 순서로 검증하세요.

# ✅ v7 학교별 양식 자동 인식 (2026-11-04)

- PDF 업로드 후 **직위·성명·서명 머리글과 표의 가로 선**을 분석하여 입력 열·행 높이·1단/2단을 자동 설정합니다.
- XLSX 업로드 후 실제 시트의 머리글과 제목/일시/장소 항목을 탐색해 저장합니다.
- 「학교 맞춤 양식 출력」의 **✨ 양식 자동 위치 인식** 버튼으로 재분석할 수 있습니다.
- 성공한 배치는 `templates.mapping`에 저장되며, 다시 선택해도 유지됩니다.
- PDF는 인식한 좌표대로 원본 페이지 위에 출력하고, Excel은 기존 시트 서식을 보존한 채 직급·성명·서명 PNG를 배치합니다.
- **글자와 표 구조가 없는 스캔 PDF, 매우 특수한 병합 표/복잡한 양식, HWP/HWPX는 자동 인식 대상이 아닙니다.** 인식 실패 시 임의 좌표로 출력하지 않고 수동 설정을 안내합니다. 인식 성공한 서식도 실제 인쇄 미리보기로 한 번 확인하세요.
- 기존 연수·참석자·서명·기본 양식은 변경하지 않습니다. 새 SQL은 필요하지 않습니다.
- Excel 양식을 선택한 상태에서 PDF로 인쇄하면 기존 기본 인쇄 양식이 적용되며, 서식을 유지하려면 Excel 파일로 내려받으세요.

# ✅ v6 모바일 서명 완료·수정 화면 (2026-11-04)

- 서명 제출이 성공하면 모바일 최적화 완료창이 나타납니다.
- 이미 등록된 서명은 `수정 / 취소` 선택창을 표시합니다.
- 동일 기기에서 v6 이후 처음 작성한 서명은 새 서명창에서 수정 가능합니다. 기기 내 수정 권한은 브라우저 저장소에 보관하고, 서버에는 해시만 비공개로 저장합니다.
- **v6 이전에 제출한 서명이나 다른 기기에서 제출한 서명은 관리자에게 서명 초기화를 요청한 뒤 재작성**해야 합니다. 이름·직급만으로 타인의 서명을 덮어쓰지 않도록 제한한 것입니다.
- 현재 연결된 elecyonsu Supabase 프로젝트에는 [v6 SQL](./migration_v6_mobile_signature_revision.sql)을 이미 적용했습니다. 새로운 Supabase 프로젝트에서는 이 SQL을 별도로 실행해야 합니다.
- 기존 데이터/서명은 v6 전환 중 변경되지 않습니다.
- 이 시스템은 성명·직급 기반의 공개 QR 제출이므로 엄격한 본인인증 서비스를 대체하지 않습니다.

# 전자 연수등록부 — 교직원 전자서명 시스템

**현재 상태:** 소스코드 게시 완료 / **Supabase 프로젝트 연결과 OAuth 설정은 별도로 필요**합니다. 연결 전에는 실제 로그인·저장·QR 서명이 작동하지 않습니다.

- 관리자: Google 로그인 또는 이메일 로그인, 연수 CRUD, 참석자·확인코드, 명단 Excel 출력/가져오기
- 참여자: 공유 QR 링크 + 개별 확인코드 + 손글씨 전자서명
- 실시간: 관리자 화면의 완료 인원·서명 상태 반영
- 출력: 기본 A4 PDF·Excel, 사용자 PDF 양식 업로드 후 좌표 매핑 출력, 사용자 Excel(.xlsx) 서식 업로드 후 셀 매핑 출력
- 파일들은 공개 GitHub 저장소에 두되 **실제 개인정보 및 서명은 업로드하지 않습니다.**

## 먼저 할 일 (상세한 화면별 설명은 SETUP.md)

1. https://supabase.com/dashboard 에서 **New project** (Free) 생성
2. Supabase **SQL Editor**에서 `supabase_setup.sql` 내용 전체 실행
3. **Project Connect** 에서 Project URL / **publishable key** 복사
4. GitHub의 `config.js`에서 두 가지 값만 변경 (secret, service_role key 절대 금지)
5. https://app.netlify.com/ 에서 **Add new project > Import an existing project > GitHub** 에서 이 저장소 선택. Build command 없음, Publish directory `.`
6. 배포 주소를 Supabase **Authentication > URL Configuration**의 Site URL 및 Redirect URLs에 등록
7. Google 로그인은 **Authentication > Sign In / Providers > Google**에서 활성화. Google Cloud에서 Web OAuth Client를 만들고 Supabase callback 주소를 등록해야 함. 먼저 이메일 인증으로 기본 기능 점검 가능
8. 실제 교사 데이터가 아닌 **가상 인원으로 반드시 동작 검증**한 후 학교 정책에 따라 승인받아 운영

## 주의
- 학교 실명·직위·서명은 개인정보입니다. 본인 확인용 개별 확인코드는 관리자만 조회·배부할 수 있습니다. 공개 QR 링크만으로 서명을 제출할 수 없습니다.
- 파일 업로드는 관리자 계정별 비공개 저장소로 분리됩니다.
- 이 앱은 **법적 공인 전자서명 또는 신분 인증 서비스가 아닙니다.**
- 무료 Supabase 프로젝트는 장기간 미사용 시 일시 정지될 수 있고, 무료 자동 백업은 보장되지 않습니다. 중요한 자료는 PDF/Excel과 DB 백업 절차를 별도로 마련하세요.
- PDF 양식은 첫 페이지를 반복하여 출력하는 방식이며 입력 위치를 직접 점 좌표로 조정합니다.
- Excel 양식은 셀·행 지정 입력이며 고급 매크로·복잡한 인쇄 레이아웃의 완전 보존을 보장하지 않습니다.
